Frequently asked questions

Answers about QR code formats and privacy.

Static or dynamic. What’s the difference?

A static QR code contains your content directly. A dynamic code usually points to a service that redirects visitors and may offer editing or tracking. FreeQR makes static codes, with no redirect service or subscription.

Will my QR code expire?

The code itself has no built-in expiry. A website it links to can change or go offline, and Wi-Fi credentials can change. Test the downloaded code with your phone before printing or sharing.

Where does my information go?

QR generation happens locally in your browser. FreeQR does not upload or store your entries, use analytics, or track scans. Opening a link from a code contacts that destination as usual.

Which file should I download?

PNG is handy for everyday sharing. SVG stays sharp at any size and is ideal for print. Keep the white border, use good contrast, and test at the final size with your intended devices.
